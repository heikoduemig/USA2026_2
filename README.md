# Route 66 After Dark Hybrid PWA v12 – kompletter Upload

Repo komplett leeren, alle Dateien hochladen, committen, dann /reset.html öffnen und „Jetzt resetten“ klicken.

Enthalten: alle 18 Locations, klickbare Karten-Marker, Popup mit Links, PWA-Manifest, Service Worker, Reset-Seite, App-Install-Button.

Hinweis: Google-Maps-Fotos können ohne Google Places Photo API nicht zuverlässig direkt eingebettet werden. Der Button „Bilder“ öffnet deshalb pro Location die passende Google-Bildersuche/Außenansicht; die Kartenbilder sind offline-stabile individuelle Artworks ohne Dopplungen.
